# Solo Founders

An operating playbook for founders building without a co-founder. Built from 38 episodes of the Solo Founders Podcast and *The State of Solo Founding* report (Solo Founders × Carta data). Every recommendation is credited to the founder or investor who said it.

## Install

In Claude Code:

```
/plugin marketplace add solo-founders/solofounders-plugin
/plugin install solofounders@solofounders
```

In Claude (desktop or web), add it from the plugin directory once it is listed.

## Skills

| Skill | What it does |
|-------|--------------|
| **solo-founder-playbook** | Always-on. Answers solo-founder questions with frameworks from podcast guests — WorkOS, Browserbase, Chatbase, Lindy, Polsia, Campfire, Fondo, and more — cited by episode. |
| **/should-i-go-solo** | Short interview on the co-founder decision. Returns a verdict, the tests that decided it, the honest bear case, and three actions for this week. |
| **/pressure-test-idea** | Scores one or more ideas against ten filters guests used (original insight, right to win, the $40K test, ten-year fit…). Returns a ranking and a two-week disproof test. |
| **/fundraise-solo** | Round strategy, angel lists, the "we don't back solo founders" answer, deck review, meeting prep, follow-ups. |
| **/first-hires** | Maps your work to you / AI agents / contractors / advisors / hires. Recommends first hires, equity ranges, and a trial plan. |
| **solo-founding-data** | Trend, dilution, and ownership data from the report. Models your own ownership path vs. a co-founded company. |
| **/solo-weekly** | A 15-minute weekly review that stands in for a co-founder: scoreboard, avoided work, decision queue, cut list. |

## Connectors

Optional. Works without any. See `CONNECTORS.md` — calendar, email, CRM, project tracker, notes, and meeting notes make `/solo-weekly` and `/fundraise-solo` pull context automatically.
